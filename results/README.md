# results/

Committed, small, and the on
ly place a reported number may come from.

- `experiments.md`: one entry per experiment (hypothesis -> setup -> result -> conclusion).
- `metrics/<run-id>.json`: output of the shared evaluator for one run, including
  per-video results and `zfpv.utils.env_info()`.
- `figures/`: plots used in the report, poster or slides.

Not here: weights, frames, anything derived from the dataset that shows its images
(dataset licence).
